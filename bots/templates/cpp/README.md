# C++ bot template

A starter bot: `hunter_move` and `prey_move` do nothing until you write your strategy
(the hunter just bounces; the prey stands still).

Copy this whole folder to `bots/<your-name>/` and edit only the section marked
`EDIT ONLY THIS SECTION` in `bot.cpp` (+ `build.py`). A working example (the "Box" bot) is in `bots/samples/`.
See the main README, "Making a bot".
